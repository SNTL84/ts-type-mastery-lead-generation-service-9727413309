# Contributing

Have a better solution or a new challenge to add?

1. Fork this repo
2. Add your solution in `solutions/` following the naming convention `{number}-{slug}.ts`
3. Include JSDoc, mental model notes, and test cases
4. Open a PR with title: `feat: add solution for #XXXX - ChallengeName`

**Quality bar:** Solutions must handle edge cases and include at least one comment explaining *why* the approach works.
